# Content Quality Gate

The question bank is structurally complete at 147 original records, but structural completeness is not the same as editorial readiness.

The automated audit checks duplicate IDs and full-item signatures, required metadata, answer-choice shape, Math SPR shape, and R&W source length against the 25–150 word guideline.

The current audit must report any R&W source below 25 words and any source containing the known generic placeholder phrase. Those findings are warnings rather than automatic CI failures because the remaining content requires deliberate editorial rewriting, not automatic filler generation.

## Release gate

Before student launch:

- all flagged R&W sources are rewritten as distinct, coherent passages or information sets;
- every question has a rationale that explains why the keyed answer is correct;
- options are plausible and mutually distinct;
- difficulty tags match the actual cognitive demand;
- adaptive Module 2 variants are substantively different, not merely renamed copies;
- a human reviewer signs off on the full 147-record set.

CI must remain structural and deterministic. Editorial review remains a human release responsibility.
